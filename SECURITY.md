# Security policy

Veld Monitor Controls runs inside GNOME Shell and talks to external monitors
through the local `ddcutil` command or the `ddcutil-service` D-Bus service.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
security advisory form:

https://github.com/Veldhost/veld-monitor-controls/security/advisories/new

Include:

- the affected version
- your GNOME Shell version and distribution
- a description of the issue and, if possible, reproduction steps

You can expect an initial response within a few days.
